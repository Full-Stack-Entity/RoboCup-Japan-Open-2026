# 数据采集策略

本文档的目标，是帮助你尽快为 Handyman 任务搭建一套可用的
自定义检测数据集与训练流程。

## 1. 首先要明确的问题

Handyman 任务共有 26 类可抓取物体，分布在 4 种房间布局 (LayoutA-D) 的
4 个房间 (BedRoom, Kitchen, Living, Lobby) 中。

当前使用的是 `yolo12n.pt`，它是标准 COCO 模型；而 COCO 并不包含很多
比赛中的关键类别，例如：

- `soysauce`
- `sugar`
- `hourglass`
- `toy_penguin`
- `cubic_clock`
- `nursing_bottle`
- `ground_pepper`

所以短期目标应当是：

- 为比赛特有类别尽快采集足够的标注数据
- 保持类别命名稳定，不要中途频繁改类名
- 避免对单一房间、单一桌面、单一距离过拟合
- 确保覆盖多种布局 (LayoutA-D) 下的不同背景

## 2. 在无法自由移动相机时，如何采集多角度数据

最快、最实用的方法是：

1. 录制短视频
2. 有意识地改变机器人底盘朝向与头部 pan/tilt
3. 从视频中按间隔抽帧
4. 只保留视角差异明显的帧做标注

建议把视角变化拆成 3 类：

### A. 底盘朝向扫描

让目标物体大致保持在机器人前方，然后让底盘在几个固定角度上停留，例如：

- `-60 deg`
- `-30 deg`
- `0 deg`
- `+30 deg`
- `+60 deg`

### B. 头部 pan / tilt 扫描

在每一个底盘朝向下，再改变头部视角：

- pan: `-0.9, -0.45, 0.0, +0.45, +0.9 rad`
- tilt: `-0.85, -0.65, -0.45 rad`

### C. 距离扫描

同一类别至少要覆盖 3 档距离：

- 近距离：物体在图像中占比较大
- 中距离：接近日常交互距离
- 远距离：物体较小，但仍然可以辨认

对于 `soysauce`、`sugar`、`hourglass` 这类小物体，必须确保有大量样本里
它们在图像中足够大。经验上建议：

- 物体宽度至少常见于 `40-60 px`
- 更理想的是经常能达到 `70+ px`（以 640 宽图像为例）

## 3. 一次高质量采集 session 应该是什么样

一个 session 最好只对应一个相对稳定的场景设置，然后在这个场景中改变视角
和距离。一个比较好的 session 往往满足：

- 一次只主采一个物体类别
- 一次只保留一种主要背景上下文
- 连续录制 `10-30 s`
- 相机运动尽量平稳，不要快速乱晃

Handyman 有 4 个房间，推荐覆盖的背景上下文包括：

- 在不同房间的桌子或架子上
- 在地面上
- 靠近杂物
- 靠近外观相似的物体
- 被家具或其他物体部分遮挡
- 在不同的 Layout (A/B/C/D) 下

不要把所有 `soysauce` 都采在同一个房间、同样灯光、同样距离下。

## 4. 每一类大概要采多少图

下面给你一个实用的分级目标：

### 最低可用基线

- 可抓取物体：每类 `150-250` 张已标注图像

### 更稳妥的基线

- 可抓取物体：每类 `300-500` 张已标注图像

### 负样本

还建议额外加入 `10-20%` 的负样本，例如：

- 没有目标物体的画面
- 只有背景杂物的画面

这些样本有助于降低误检率。

注意：不要把视频里几乎一模一样的相邻帧都算成"有效新样本"。10 张真正不同
的视角，往往比 100 张几乎重复的图更有价值。

## 5. 如何从视频中抽帧

建议起步时按 `0.3-0.6 s` 抽取一帧。

抽帧后，手动删掉这些图：

- 和前后帧几乎一样
- 明显有运动模糊
- 太暗
- 目标太小，小到几乎无法可靠标注

实际经验里，一段 `20 s` 的视频，经过抽帧与人工筛选后，通常会得到
`25-50` 张真正值得标注的图。

## 6. 标注规则

请统一使用 YOLO 格式标注，并且全程使用同一套类别表。

建议遵守以下规则：

- 只标注你能明确视觉识别的目标
- 框尽量贴近物体边界，但不要把物体截断
- 遮挡太严重、类别已经不确定时，宁可不标
- 只要这个物体的可见程度足以影响运行时识别，就应当标出来
- 不同人、不同 session 的命名必须完全一致

### Handyman 特有的易混淆类别

Handyman 比 Interactive Cleanup 多了很多相似类别，需要特别注意：

- `sauce` vs `soysauce` — 采集正面、侧面、背面
- `filled_ketchup` vs `empty_ketchup` — 注意瓶身膨胀程度差异
- `filled_plastic_bottle` vs `empty_plastic_bottle` — 注意液面高度
- `pink_cup` vs `white_cup` vs `tumbler` — 颜色和形状差异
- `sugar` vs `salt` vs `ground_pepper` — 容器外观相似
- `bear_doll` vs `rabbit_doll` vs `dog_doll` — 形态差异

## 7. 数据集切分策略

不要把同一个短视频里的单帧随机拆到 train 和 val 中。这样会把高度相似的图像
泄漏到不同集合，导致验证分数虚高。

正确做法是按 session 切分：

- 一个完整 session 整体分到 `train`、`val` 或 `test`
- 推荐比例约为 `70/20/10` 或 `75/15/10`
- 关键类别要保证在 `val` 和 `test` 中都出现

当前提供的 `split_dataset.py` 就是按这种"基于 session 的切分方式"设计的。

## 8. 数据增强策略

开始时建议保守一些。Ultralytics 默认增强本身就已经够用。

比较适合的增强包括：

- 小幅 HSV 扰动
- 轻度缩放与平移
- 在语义合理时进行水平翻转
- 训练前期使用 mosaic
- 在最后若干 epoch 用 `close_mosaic` 关闭 mosaic

一开始不建议使用太激进的增强，例如：

- 很强的透视形变
- 很重的模糊
- 极端色彩变化
- 大范围随机裁剪，导致小物体被抹掉

对于这个任务来说，保住小物体细节通常比做很花哨的增强更重要。

## 9. 要刻意补采的困难样本

建议专门为失败场景建立一些 session，例如：

- 物体被其他物体部分遮挡
- 物体靠近相似容器或瓶子
- 物体靠近桌边
- 物体处在阴影里
- 背景纹理复杂
- 物体在图中非常小
- 跨房间采集（BedRoom, Kitchen, Living, Lobby）

### Handyman 特有的困难场景

- `empty_ketchup` 与 `filled_ketchup` 在远距离时容易混淆
- `salt`、`sugar`、`ground_pepper` 三者外形相近
- `pink_cup`、`white_cup`、`tumbler` 需要区分颜色和形状
- `toy_duck`、`toy_penguin`、`toy_car` 在远距离时的细节
- LayoutD 包含最多的 26 种物体，场景最密集

## 10. 第一周最推荐的推进方式

如果你想尽快见效，我建议先这样做：

1. 先挑 `6-8` 个 COCO 明显识别不好的关键抓取类
2. 每个关键类先采 `200-300` 张
3. 训练出第一版基线模型
4. 上机器人实测，并记录失败案例
5. 只补采你真实失败过的场景
6. 再训练第二版

由于 Handyman 有 26 类（比 Interactive Cleanup 的 13 类多一倍），
建议优先关注 Handyman 独有的 14 类中 COCO 无法识别的物体。

## 11. 推荐工具

你可以使用任何支持 YOLO 标注格式的工具，比较实用的包括：

- AnyLabeling
- labelImg
- CVAT

真正重要的不是工具本身，而是：

- session 是否足够多样
- 类别命名是否始终一致
- 是否避免了大量重复帧
