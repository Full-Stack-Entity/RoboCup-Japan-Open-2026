# 数据采集策略

本文档的目标，是帮助你尽快为 Interactive Cleanup 任务搭建一套可用的
自定义检测数据集与训练流程。

## 1. 首先要明确的问题

你当前的瓶颈不只是搜索策略，视觉模型本身也不够匹配比赛物品。

现在使用的是 `yolo12n.pt`，它是标准 COCO 模型；而 COCO 并不包含很多
比赛中的关键类别，例如：

- `soysauce`
- `sugar`
- `hourglass`
- `toy_penguin`

所以短期目标应当是：

- 为比赛特有类别尽快采集足够的标注数据
- 保持类别命名稳定，不要中途频繁改类名
- 避免对单一房间、单一桌面、单一距离过拟合

## 2. 在无法自由移动相机时，如何采集多角度数据（已经通过修改Csharp脚本实现摄像机的自由移动解决）

如果你无法像“自由飞行相机”那样围着物体拍摄，就不要把主要精力放在手工拍
很多静态照片上。最快、最实用的方法是：

1. 录制短视频
2. 有意识地改变机器人底盘朝向与头部 pan/tilt
3. 从视频中按间隔抽帧
4. 只保留视角差异明显的帧做标注

建议把视角变化拆成 3 类：

### A. 底盘朝向扫描

让目标物体大致保持在机器人前方，然后让底盘在几个固定角度上停留，例如：

- `-60 deg`
- `-30 deg`
- `0 deg`
- `+30 deg`
- `+60 deg`

当相机无法自由在空间中移动时，这是制造“左视角 / 正视角 / 右视角”差异最
有效的方法。

### B. 头部 pan / tilt 扫描

在每一个底盘朝向下，再改变头部视角：

- pan: `-0.9, -0.45, 0.0, +0.45, +0.9 rad`
- tilt: `-0.85, -0.65, -0.45 rad`

这种方式得到的是“机器人真实运行时会看到的视角”，通常比随意造一些不自然
的角度更有价值。

### C. 距离扫描

同一类别至少要覆盖 3 档距离：

- 近距离：物体在图像中占比较大
- 中距离：接近日常交互距离
- 远距离：物体较小，但仍然可以辨认

对于 `soysauce`、`sugar`、`hourglass` 这类小物体，必须确保有大量样本里
它们在图像中足够大。经验上建议：

- 物体宽度至少常见于 `40-60 px`
- 更理想的是经常能达到 `70+ px`（以 640 宽图像为例）

## 3. 一次高质量采集 session 应该是什么样

一个 session 最好只对应一个相对稳定的场景设置，然后在这个场景中改变视角
和距离。一个比较好的 session 往往满足：

- 一次只主采一个物体类别
- 一次只保留一种主要背景上下文
- 连续录制 `10-30 s`
- 相机运动尽量平稳，不要快速乱晃

推荐覆盖的背景上下文包括：

- 在桌子或架子上
- 在地面上
- 靠近杂物
- 靠近外观相似的物体
- 被家具或其他物体部分遮挡

不要把所有 `soysauce` 都采在同一张桌子、同样灯光、同样距离下。这样训练出
来的模型很容易记住“场景”，而不是记住“物体本身”。

## 4. 每一类大概要采多少图

下面给你一个实用的分级目标：

### 最低可用基线

- 可抓取物体：每类 `150-250` 张已标注图像

### 更稳妥的基线

- 可抓取物体：每类 `300-500` 张已标注图像

### 负样本

还建议额外加入 `10-20%` 的负样本，例如：

- 没有目标物体的画面
- 只有背景杂物的画面

这些样本有助于降低误检率。

注意：不要把视频里几乎一模一样的相邻帧都算成“有效新样本”。10 张真正不同
的视角，往往比 100 张几乎重复的图更有价值。

## 5. 如何从视频中抽帧

建议起步时按 `0.3-0.6 s` 抽取一帧。

抽帧后，手动删掉这些图：

- 和前后帧几乎一样
- 明显有运动模糊
- 太暗
- 目标太小，小到几乎无法可靠标注

实际经验里，一段 `20 s` 的视频，经过抽帧与人工筛选后，通常会得到
`25-50` 张真正值得标注的图。

## 6. 标注规则

请统一使用 YOLO 格式标注，并且全程使用同一套类别表。

建议遵守以下规则：

- 只标注你能明确视觉识别的目标
- 框尽量贴近物体边界，但不要把物体截断
- 遮挡太严重、类别已经不确定时，宁可不标
- 只要这个物体的可见程度足以影响运行时识别，就应当标出来
- 不同人、不同 session 的命名必须完全一致

对于 `sauce` 和 `soysauce` 这种容易混淆的类别，一定要采集：

- 正面
- 侧面
- 背面

否则模型很容易只记住某一面标签贴纸的样子。

## 7. 数据集切分策略

不要把同一个短视频里的单帧随机拆到 train 和 val 中。这样会把高度相似的图像
泄漏到不同集合，导致验证分数虚高。

正确做法是按 session 切分：

- 一个完整 session 整体分到 `train`、`val` 或 `test`
- 推荐比例约为 `70/20/10` 或 `75/15/10`
- 关键类别要保证在 `val` 和 `test` 中都出现

当前提供的 `split_dataset.py` 就是按这种“基于 session 的切分方式”设计的。

## 8. 数据增强策略

开始时建议保守一些。Ultralytics 默认增强本身就已经够用。

比较适合的增强包括：

- 小幅 HSV 扰动
- 轻度缩放与平移
- 在语义合理时进行水平翻转
- 训练前期使用 mosaic
- 在最后若干 epoch 用 `close_mosaic` 关闭 mosaic

一开始不建议使用太激进的增强，例如：

- 很强的透视形变
- 很重的模糊
- 极端色彩变化
- 大范围随机裁剪，导致小物体被抹掉

对于这个任务来说，保住小物体细节通常比做很花哨的增强更重要。

## 9. 要刻意补采的困难样本

建议专门为失败场景建立一些 session，例如：

- 物体被其他物体部分遮挡
- 物体靠近相似容器或瓶子
- 物体靠近 Avatar 的手或手臂
- 物体靠近桌边
- 物体处在阴影里
- 背景纹理复杂
- 物体在图中非常小

如果 `soysauce` 是关键类别，建议额外覆盖：

- 直立与倾斜摆放
- 正面朝向镜头、背面朝向镜头
- 靠近其他瓶装物
- 多个距离
- 多种支撑面

## 10. 第一周最推荐的推进方式

如果你想尽快见效，我建议先这样做：

1. 先挑 `4-6` 个 COCO 明显识别不好的关键抓取类
2. 每个关键类先采 `200-300` 张
3. 训练出第一版基线模型
5. 上机器人实测，并记录失败案例
6. 只补采你真实失败过的场景
7. 再训练第二版

这种迭代方式，通常比一开始就想把全量数据一次采满更快见效。

## 11. 推荐工具

你可以使用任何支持 YOLO 标注格式的工具，比较实用的包括：

- AnyLabeling
- labelImg
- CVAT

真正重要的不是工具本身，而是：

- session 是否足够多样
- 类别命名是否始终一致
- 是否避免了大量重复帧
