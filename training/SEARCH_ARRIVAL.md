# 搜索点到达确认（离线模块）

`scripts/search_arrival.py` 将匹配导航结果、停稳证据和视觉观察起始时间连接起来。
目前不订阅 ROS、不发送导航目标，不能代替实机搜索验收。

调用顺序：创建 SearchScan 与 SearchArrival（绑定唯一 goal_id）→ 最终搜索点
导航成功后调用 result → 持续提供同一时间戳的 map 位姿和实测速度 →
通过后使用 gate.adapter 消费新的视觉记录。

初始阈值：距离不超过 0.15 米，朝向误差不超过 10 度，线速度不超过
0.02 米/秒，角速度不超过 0.03 弧度/秒；至少持续 1 秒。停稳期间位置
相对起始点漂移不得超过 0.02 米、朝向漂移不得超过 0.03 弧度。
样本必须新鲜（0.5 秒以内），连续采样间隔不得超过 0.5 秒；传感器时间和
单调时钟都必须跨过 1 秒，暂停不能凑够停稳时长。这些阈值尚待实时调试。

ROS 接线要求：

- result 必须对应最终搜索位姿的唯一目标，不接受“已进入房间”作为替代。
- 输入位姿为 map → base_footprint；实测速度来自同时间的里程计，
  线速度应为平面速度模长，不能用 cmd_vel 为零替代实际停稳。
- TF 必须查输入里程计的精确时间；缺失、断流时不能沿用旧证据。
- now 为单调时钟；stamp_ns 和 sensor_now_ns 为同一 ROS 传感器时钟。
- 导航失败仍由导航恢复层处理；本模块不会据此判断物品不存在。
- 任务取消或换搜索点必须弃用旧模块；观察期间移动的持续监控尚未接入。

不改变第三阶段导航和穿门代码，不证明完整房间覆盖，不发送比赛消息。
